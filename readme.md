# Calculadora de Consumo de Energia

Programa desenvolvido em **Python** para calcular o consumo mensal de energia de um eletrodoméstico e seu custo estimado.

## Fórmulas

* Consumo mensal = (Potência × Horas por dia × 30) ÷ 1000
* Custo = Consumo × 0,75

## Como executar

1. Execute o arquivo `app.py`.
2. Digite o nome do eletrodoméstico.
3. Informe a potência e as horas de uso por dia.
4. O programa mostrará o consumo mensal e o custo estimado.
